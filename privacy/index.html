Privacy

Last updated 9 November 2026

This website

This site doesn't use cookies, tracking pixels, advertising or contact forms. Everything you see is served from this site itself.

To count visits, the site uses Cloudflare Web Analytics, which loads one small script from Cloudflare. It doesn't use cookies or identify you; it records anonymous totals such as pages viewed, the referring site, browser type and country. Cloudflare handles that data under the Cloudflare privacy policy.

The site is hosted on GitHub Pages. Like any web host, GitHub may keep standard server logs, such as IP addresses and the pages requested, under GitHub's privacy statement. GW Automation doesn't receive or use those logs.

When you email us

If you email gwautomation@gwstudio.com.au, your name, email address and anything you include are used only to reply to you and to provide trials, quotes, licences and support. They aren't sold, shared for marketing or added to a mailing list.

The software

HistorianLink and OpcDaLink run on your own machines. Licensing is checked offline on the machine itself: the software doesn't phone home, send telemetry or need internet access. Your plant data stays on your network.

Reporting a security issue

If you think you've found a security problem in HistorianLink or OpcDaLink, email gwautomation@gwstudio.com.au with "Security" in the subject. Include the version and how to reproduce it. Please give us time to fix it before sharing details publicly.

Questions

Email gwautomation@gwstudio.com.au and you'll get an answer from the developer directly.
