Licence terms

Applies to HistorianLink and OpcDaLink · Last updated 10 November 2026

How licensing works

  • Per site, perpetual. One licence covers a site and does not expire. There is no per-tag pricing.
  • Not tied to a machine. Replacing, rebuilding or moving a server does not need a new licence.
  • Fully offline. Each site receives a digitally signed licence file that is checked on the machine. There is no activation server and the software never needs internet access.
  • Free 90-day trial. A trial licence has the full feature set and no tag limit. A full licence added at any point replaces it with no reinstall, and your configuration is kept.
